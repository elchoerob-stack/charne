How CMS admin jobs work
Foreman doesn't know what your CMS admin screens look like, so it learns from you. For each kind of user job:
  1. Do the job once with the recorder running, using a test user. Press Make a task on the recording.
  2. Come back here and pick that task for the job below.
  3. Tell Foreman which step presses Save, which fields hold the dealer, name, e-mail and role, and what message CMS shows when the save worked.
Everything before the Save step is shown to you for approval, so make sure nothing before it saves anything (no auto-save, no "Next" that creates the record). The Save only happens after you approve it, and only counts if CMS shows the message you give here.
You also need to be signed in to CMS admin: on the Foreman screen open Sites and sign in once a day.
