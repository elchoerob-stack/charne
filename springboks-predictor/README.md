# Springboks Tour Predictor

The CMS office score-prediction game for the Springboks' Tests: pick the
scores, closest wins, with wi — the CMS assistant — as the in-app guide.

A single static page (`index.html`) served by GitHub Pages, with its own
Firebase/Firestore project for picks and results. It is deliberately
separate from any other predictor: its own address, its own database.

Live: https://elchoerob-stack.github.io/springboks-predictor/
